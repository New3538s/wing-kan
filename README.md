# Wing kan

เว็บแอปต้นแบบเกมเดินหรือปั่นจักรยานสำรวจย่าน แลกแต้มเป็นคูปองจำลอง สร้างด้วย HTML, CSS และ JavaScript ล้วน ไม่ต้องใช้ API key

## พื้นที่ทดลอง

ระยะแรกจำกัดจุดแนะนำและเส้นทางจริงไว้ในจังหวัดนนทบุรี โดยใช้ขอบเขตจังหวัดจาก OpenStreetMap จุดสาธิตอยู่บริเวณเกาะเกร็ดและติดป้ายว่าเป็นตัวอย่าง หากอนุญาต GPS นอกนนทบุรี แอปจะแจ้งให้เข้าเขตพื้นที่ทดลองหรือใช้โหมดสาธิต

## วิธีเล่น

1. เลือกเดินหรือปั่นจักรยาน แล้วเลือก **ยึดจุดทั่วไป** หรือ **เที่ยวสำรวจ**
2. กดเริ่ม GPS และอนุญาตตำแหน่ง หรือเลือกโหมดสาธิต
3. แอปแนะนำจุดใกล้ตัวในนนทบุรีจาก OpenStreetMap และคำนวณเส้นทางตามถนนผ่านบริการสาธารณะ หากบริการหรืออินเทอร์เน็ตไม่พร้อม แอปจะแสดงแผนที่ตัวอย่างและระยะโดยประมาณแทน
4. แตะจุดเพื่ออ่านรายละเอียดและทำภารกิจ เช็กอินรับ 10 แต้มเมื่ออยู่ในระยะ 50 เมตร
5. โหมดยึดจุดทั่วไปต้องเก็บจุดในลูปให้ครบและกลับมาใกล้จุดเริ่มภายใน 50 เมตรเพื่อรับโบนัส 20 แต้ม ส่วนโหมดเที่ยวสำรวจต้องตอบคำถามของแต่ละจุดและเก็บจุดให้ครบเพื่อรับโบนัส 20 แต้ม
6. ใช้แต้มแลกคูปองจำลอง หรือดูผลการเดินทางในหน้าสรุป

ผู้เล่นแต่ละคนรับแต้มจากจุดเดิมได้ครั้งเดียวต่อรอบ ความคืบหน้าและคูปองเก็บใน localStorage ของอุปกรณ์นี้ จุดและร้านในโหมดสาธิต รวมถึงชื่อเจ้าของจุดจำลอง ไม่ใช่ข้อมูลการเข้าร่วมจริง และยังไม่มีระบบซิงก์ผู้เล่นระหว่างอุปกรณ์

## เปิดใช้งาน

หากเปิด index.html ตรงจาก file URL แอปจะแสดงแผนที่ตัวอย่างแทนแผนที่ถนน เพราะ OpenStreetMap ต้องใช้ Referer ที่เว็บไฟล์ไม่สามารถส่งได้ เพื่อดูแผนที่จริงให้เปิดเว็บผ่านเซิร์ฟเวอร์หรือ HTTPS นโยบายระบุให้แอปแสดงเครดิต ใช้ URL tile ตามที่กำหนด และเคารพ cache ของเบราว์เซอร์ [OpenStreetMap Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/)

เมื่อกดอนุญาต GPS แอปจะส่งพิกัดไปยัง Overpass เพื่อค้นหาจุดที่อยู่ในเขตนนทบุรี และส่งพิกัดจุดตามเส้นทางไปยัง OSRM/FOSSGIS เพื่อคำนวณทางเดินหรือจักรยาน ไม่มี API key แบบเสียเงิน แต่บริการสาธารณะเป็นแบบ best-effort และข้อมูลสถานที่อาจไม่ครบ เส้นทางอาจเป็นเส้นเชื่อมโดยประมาณเมื่อคำนวณเส้นทางถนนไม่ได้ แอปนี้ไม่ใช่ระบบนำทางเลี้ยวต่อเลี้ยว

Geolocation บนโทรศัพท์ต้องเปิดเว็บผ่าน HTTPS และกดอนุญาตตำแหน่งเมื่อเบราว์เซอร์ถาม การเปิดผ่าน HTTP บน Wi-Fi อาจเข้าแอปได้แต่เบราว์เซอร์มือถือมักปิดกั้น GPS ส่วน http://localhost ใช้ทดสอบบนเครื่องที่รันเว็บเซิร์ฟเวอร์ได้

หากติดตั้ง Node.js แล้ว เปิด PowerShell ในโฟลเดอร์ outputs/wing-kan แล้วรัน:

~~~powershell
node serve.cjs
~~~

จากนั้นเปิด <http://localhost:8000> และกด “เริ่ม GPS” โหมดสาธิตใช้ได้โดยไม่ต้องเปิด GPS หรืออินเทอร์เน็ตสำหรับข้อมูลจุดตัวอย่าง

## Dashboard ร้านค้า

หน้าสำหรับร้านค้าแสดงจำนวนเช็กอิน จำนวนคูปองที่แลก และยอดเข้าชมเป็น **ข้อมูลสาธิต** เพื่ออธิบายรายได้จากค่าร่วมแคมเปญ/สนับสนุนจุดเช็กอิน และค่าธรรมเนียมคูปอง ยังไม่มีการเรียกเก็บเงินจริง

ข้อมูลภาษา โหมดสี/มืด แต้ม และคูปองเก็บไว้ใน localStorage ปุ่มเริ่มใหม่ในหน้าสรุปล้างความคืบหน้าเกมบนอุปกรณ์นี้

## เผยแพร่บน GitHub Pages

โฟลเดอร์นี้มี workflow สำหรับเผยแพร่เว็บแบบ static ผ่าน GitHub Actions ที่ `.github/workflows/deploy-pages.yml` แล้ว ให้นำ **เนื้อหาทั้งหมดในโฟลเดอร์ `wing-kan`** ไปวางเป็นไฟล์ระดับบนสุด (root) ของ repository ใหม่ จากนั้น push ไปยัง branch `main` และตั้งค่า repository ที่ **Settings → Pages → Build and deployment → Source: GitHub Actions** เมื่อ workflow ทำงานสำเร็จ เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repository>/` และเปิดจากโทรศัพท์ได้

เว็บ Pages จะเข้าถึงได้สาธารณะ ผู้ใช้ต้องอนุญาตตำแหน่งในเบราว์เซอร์ และเปิด Location/GPS ของโทรศัพท์เพื่อใช้ GPS จริง หากยังไม่ได้สร้าง repository ให้สร้าง repository แล้วส่ง URL มา เพื่อเตรียมขั้นตอนเผยแพร่ต่อได้
